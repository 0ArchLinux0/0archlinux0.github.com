[Link] <https://www.acmicpc.net/problem/1009>

For each test case, compute the last digit of `a^b` by binary exponentiation modulo 10. This avoids trying to discover a repeating cycle and works for every base, including bases divisible by 10. The result identifies the computer numbered by that digit, except that a remainder of 0 means computer 10 (the computers are numbered 1 through 10).

The program reads the test-case count and then processes each `(a, b)` pair independently. Its running time per case is `O(log b)`.

## Java

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader input = new BufferedReader(new InputStreamReader(System.in));
        int testCases = Integer.parseInt(input.readLine().trim());
        StringBuilder output = new StringBuilder();

        for (int test = 0; test < testCases; test++) {
            String[] values = input.readLine().trim().split("\\s+");
            int a = Integer.parseInt(values[0]);
            long b = Long.parseLong(values[1]);
            int lastDigit = (int) powerModuloTen(a, b);
            output.append(lastDigit == 0 ? 10 : lastDigit).append('\n');
        }

        System.out.print(output);
    }

    static long powerModuloTen(int base, long exponent) {
        long result = 1;
        long factor = base % 10;
        while (exponent > 0) {
            if ((exponent & 1) != 0) result = (result * factor) % 10;
            factor = (factor * factor) % 10;
            exponent >>= 1;
        }
        return result;
    }
}
```
